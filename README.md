Instrucciones para visualizar el proyecto

Ingresar al repositorio ACTIVIDAD-INTEGRADORA-1 en GitHub.
Hacer clic en el botón verde Code.
Seleccionar Download ZIP para descargar el proyecto.
Descomprimir el archivo ZIP en una carpeta de la computadora.
Abrir la carpeta del proyecto en Phoenix Code o Visual Studio Code.
Buscar el archivo index.html.
Abrir index.html en un navegador web, como Google Chrome, o utilizar la vista previa de Phoenix Code.
Comprobar que las imágenes, los estilos CSS y las funciones JavaScript se visualicen correctamente.
